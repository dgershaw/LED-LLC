# Light Efficient Design website (test copy)

A preview of the new Light Efficient Design, RemPhos and Solera website, published with GitHub Pages so it can be shared without a Claude login.

- Every page is generated by `tools/build.py` from `data/`, `content/` and the templates in `tools/templates/`. After every push, the "Build the site" GitHub Action runs the build, commits the result and publishes it, so never edit the HTML pages directly.
- `TEST_COPY` marks this as the test copy: pages carry a `noindex` tag and `robots.txt` blocks crawlers, so it stays out of search results. Remove that file at go-live.
- Part numbers and specifications come from the 2026 Full Product Catalog and the spec sheets supplied so far.

## The admin page

Sign in at https://app.pagescms.org and open this repository (configured by `.pages.yml`). Every save is a commit; the site rebuilds itself and the change is live a few minutes later.

### Product pages

Each product page's title, headline, introduction, key points, "At a glance" features, part-number tables and footnotes can be edited under **Product pages**, in one folder per Products menu category (the files in `content/pages/<category>/`). A page listed under two categories sits in the first one.

- A table row is one line with its cells in column order, separated by `|`. Wrap a value in `**double asterisks**` to mark the factory default. An empty cell is nothing between two `|` marks.
- Photos, downloads, the LBI configurator and the layout of the spec-sheet-led pages are set in the generator, not on the admin page.

### Spec sheets, instructions, IES files and case studies

- To post a newer version of a document, upload it under the same name with a version or date added: `RP-LBI-Spec_Sheet V2.pdf`, `LBI-G2-Spec-Sheet-rev3.pdf` or `LBI-G2-Spec-Sheet-2026-10-12.pdf`. Every link to that document then opens the newest one. The older version can stay as a record or be deleted.
- Recognized endings: `V2`, `v2`, `ver 2`, `version 2`, `rev3`, `revision 3`, or a date (`2026-10-12`, `10.12.26`, `20261012`), after a space, dash, underscore or dot. A higher version wins; with dates, the latest date wins.
- Uploading a second file under exactly the same name saves it as `name-1.pdf`, which no page links to, so always add a version or date (or delete the old file first).
- A brand-new document (not a new version of one already on the site) is stored right away but appears on a page only once Claude links it. Ask in the project thread.
