Linear T5 + T8

Energy-saving replacements for fluorescent T8 and T5.

Every size and installation method you need — in the highest quality, best light output design. Install our retrofits to get worry-free operation for years to come.

Type A + B — FlexColor T8 (G13) and T5 (G5 mini bi-pin).
